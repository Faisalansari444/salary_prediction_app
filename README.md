# salary_prediction_app
A lightweight, user-friendly Machine Learning web application that predicts employee salaries based on years of experience. Built using Python, Scikit-Learn, and Streamlit, this project demonstrates an end-to-end ML workflow from data preprocessing and model training to deployment.

Accurate Predictions: Utilizes a Simple Linear Regression model trained on professional experience datasets.

Interactive UI: Built with Streamlit, allowing users to input any number of years of experience and instantly receive a predicted salary.

Data Visualization: Displays scatter plots and the regression line to visually represent the relationship between experience and salary.

Clean & Modular Code: Organized codebase adhering to best practices for reproducibility.
